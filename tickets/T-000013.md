## Goal
Cache the `SyntaxHighlighter` instance in `MacOSTextEditor.Coordinator` (and `iOSTextEditor.Coordinator`) instead of re-creating it on every `textDidChange` and `applySyntaxHighlighting` call. Invalidate only when `fileType`, `fileName`, or `theme` changes.

## Acceptance Criteria
- [ ] SyntaxHighlighter is created once and reused across keystrokes
- [ ] Highlighter is invalidated when fileType, fileName, or theme changes
- [ ] No visual regression in syntax highlighting

## Notes
Files: `qw/Editor/CodeEditorView.swift:666` (macOS), `:915` (iOS)
Both coordinators already track `fileType`, `fileName`, and `theme` — just need to store and invalidate a cached `SyntaxHighlighter`.
