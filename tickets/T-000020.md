## Goal
Add editing capabilities to the hex view: click-to-select a byte, overwrite by typing hex digits or ASCII characters, insert/delete bytes, and full undo/redo support.

## Acceptance Criteria
- [ ] Clicking a byte in the hex pane selects it (highlighted cursor)
- [ ] Clicking a character in the ASCII pane selects the corresponding byte
- [ ] Typing two hex digits (0-9, a-f) overwrites the selected byte and advances cursor
- [ ] Typing a character in ASCII pane overwrites the byte with that character's value
- [ ] Insert mode: insert a new byte at cursor position (with confirmation dialog for size-changing edits)
- [ ] Delete: remove byte at cursor position (with confirmation dialog)
- [ ] Undo/redo works for all edit operations (Cmd+Z / Cmd+Shift+Z)
- [ ] Modified indicator shown in title bar / tab when hex data has unsaved changes
- [ ] Save writes modified bytes back to file

## Notes
Edits should be stored as a patch list (offset, old bytes, new bytes) rather than copying the entire file into memory. This is critical for large file support (T-000023). Build the `HexDocument` model to manage this edit buffer.
