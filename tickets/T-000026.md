## Goal
Color-code distinct sections (file header, metadata, payload/data) in the hex view based on detected file type, with a legend sidebar or tooltip explaining each section

## Acceptance Criteria
- [ ] Each file type defines named sections with byte ranges (e.g. PNG: signature 0-7, IHDR chunk 8-32, data chunks, IEND)
- [ ] Sections are color-coded with distinct background colors in the hex view (header=blue, metadata=green, payload=gray, etc.)
- [ ] A legend or sidebar shows the section names and their color mapping
- [ ] Hovering or selecting bytes within a section shows the section name
- [ ] Supports at least PNG, JPEG, PDF, and ELF section layouts

## Notes
Depends on T-000025 for file type detection. Section definitions should be extensible — a protocol or struct like `FileLayout` with an array of `Section(name:, range:, color:)`. Start with PNG (well-documented chunk format) as the reference implementation.
