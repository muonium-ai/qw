## Goal
Show inline annotations for recognized byte patterns (e.g. 0x89504E47 → PNG signature, 0x7F454C46 → ELF header) as tooltips or a side panel with human-readable explanations of struct fields

## Acceptance Criteria
- [ ] Magic byte signatures show inline annotations (e.g. `89 50 4E 47` annotated as "PNG signature")
- [ ] Struct fields are decoded and labeled (e.g. PNG IHDR: width, height, bit depth, color type)
- [ ] Annotations appear as tooltips on hover or in a collapsible side panel
- [ ] Integer fields show both hex and decimal values (e.g. `00 00 03 20` → "Width: 800")
- [ ] Endianness is handled correctly per file format (big-endian for PNG, little-endian for ELF)

## Notes
Depends on T-000025 for file type detection. Start with PNG IHDR chunk interpretation as the reference. Use a `FieldDescriptor` approach: each file format provides an array of `(name, offset, size, type, endianness)` entries that get rendered as annotations. Consider a protocol `FileFormatInterpreter` for extensibility.
