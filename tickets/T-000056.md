## Goal
Run WebAssembly binaries inside wasmtime (preferred, Bytecode Alliance, most secure) or wasmer as fallback. WASM is inherently sandboxed — no filesystem/network unless explicitly granted via WASI. Execution must use the sandbox framework from T-000055. Detect wasmtime/wasmer on PATH, show install prompt if missing. Capture stdout/stderr, enforce memory limit (256MB default), CPU timeout (30s default). Display output in a terminal-like panel within the hex view.
