## Goal
Run native Mach-O and ELF executables inside macOS sandbox-exec with a strict seatbelt profile. DENY ALL by default, then allow only: read of the executable itself, write to a private tmpdir (auto-cleaned), stdout/stderr. NO network, NO process-spawn, NO signal sending, NO IPC, NO device access, NO home directory access. ELF on macOS requires Rosetta or QEMU-user — detect and inform user. Enforce RLIMIT_CPU (30s), RLIMIT_AS (512MB), RLIMIT_FSIZE (10MB). Kill on timeout. Show confirmation dialog with permission summary before execution. Capture and display output in terminal panel.
