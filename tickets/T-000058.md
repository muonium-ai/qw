## Goal
Run Windows PE executables via Wine (detect on PATH, prompt for install if missing). Wine itself must run inside sandbox-exec seatbelt profile: no network, restricted filesystem (only WINEPREFIX tmpdir), no access to real home/documents. Create disposable WINEPREFIX per execution in a temp directory, auto-delete after. Enforce CPU timeout (60s), memory limit. Warn user that Wine execution carries inherent risk — require explicit confirmation with a clear permission summary. Capture Wine stdout/stderr and display in terminal panel.
