## Root Cause
HexSearchState is an `ObservableObject` (class). When instantiated via `@testable import qw` in XCTest on macOS 26, it crashes on dealloc:
- `___BUG_IN_CLIENT_OF_LIBMALLOC_POINTER_BEING_FREED_WAS_NOT_ALLOCATED`
- `swift::TaskLocal::StopLookupScope::~StopLookupScope()`
- Tests complete in 0.000 seconds (process crash, not assertion failure)
