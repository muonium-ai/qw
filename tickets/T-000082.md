## Goal
Unskip 2 SyntaxHighlighterTests that crash on macOS 26 due to SyntaxHighlighter class dealloc

## Acceptance Criteria
- [ ] Both SyntaxHighlighter tokenize tests pass (not skipped)
- [ ] No test runner crashes during SyntaxHighlighter tests

## Root Cause
Same as T-000081. `SyntaxHighlighter` is a class that crashes on dealloc when instantiated via `@testable import qw` in XCTest on macOS 26. The `tokenize()` method itself works, but process crashes when the instance is deallocated.

## Skipped Tests (in SyntaxHighlighterTests.swift)
1. testCommentShouldNotContainStringTokens_JavaScript
2. testCommentShouldNotContainStringTokens_Python

## Possible Approaches
- Extract `tokenize()` logic into a standalone struct or static function
- Make SyntaxHighlighter a struct instead of a class (if no reference semantics needed)
- Use @MainActor isolation to control dealloc timing
- Test via a subprocess that calls tokenize and reports results
