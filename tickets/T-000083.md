## Goal
Unskip testPNGExportCreatesFile that crashes on macOS 26 during AppKit rendering in test runner

## Acceptance Criteria
- [ ] testPNGExportCreatesFile passes (not skipped)
- [ ] Exported PNG file exists and has non-zero size
- [ ] No test runner crashes

## Root Cause
`DocumentExporter` is a plain class (not ObservableObject), but `exportToPNG()` calls `CodeRender.renderPNG()` which uses AppKit rendering (`NSAttributedString`, `NSBitmapImageRep`). This crashes in the headless test runner on macOS 26. Test completes in 0.000 seconds (process crash).

## Skipped Tests (in DocumentExporterTests.swift)
1. testPNGExportCreatesFile

## Possible Approaches
- Run the export in a subprocess to isolate the crash
- Mock the rendering layer and test the export pipeline without actual AppKit rendering
- Use XCUITest to drive the export through the app UI instead
- Test the AttributedString creation separately from the PNG rendering
- Wait for Apple fix
