## Goal
When the user searches for text, highlight all matches in the editor text view (e.g. with a background color) and scroll to / distinctly highlight the current match. Currently `SearchState` tracks matches and the current match index, but the `MacOSTextEditor` Coordinator does not render any visual indicators.

## Acceptance Criteria
- [ ] All search matches are highlighted with a visible background color in the text view
- [ ] The current match is highlighted with a distinct color (e.g. brighter/different background)
- [ ] Editor scrolls to the current match when navigating with Find Next / Find Previous
- [ ] Highlights are cleared when search is dismissed
- [ ] Works correctly with syntax highlighting (highlights overlay token colors)

## Notes
The `SearchState` object is available via `@FocusedValue` but is not currently passed to `CodeEditorView` or the text editor coordinators. Will need to wire it through and apply `NSTextView` temporary attributes or background color attributes for matches.
