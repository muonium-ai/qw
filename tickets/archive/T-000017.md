## Goal
Fix the search match counter in `SearchReplaceView` which always displays "0/0". The `@State` properties `matchCount` and `currentMatch` are only set by `updateMatchInfo(current:total:)` which is never called. The actual match data lives in `SearchState.matches` and `SearchState.currentMatchIndex`.

## Acceptance Criteria
- [ ] Match counter displays correct total (e.g. "3/10")
- [ ] Current match index updates when navigating with Find Next / Find Previous
- [ ] Counter resets to "0/0" when search text is cleared
- [ ] Counter shows "0/0" when there are no matches

## Notes
File: `qw/Views/SearchReplaceView.swift:123-126`
Either remove the `@State` properties and `updateMatchInfo` method and bind directly to `SearchState` properties, or call `updateMatchInfo` from the parent. Binding to `SearchState` is cleaner.
