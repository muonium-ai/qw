## Goal
Build a read-only hex viewer that displays file contents in canonical hex dump format: an offset gutter, hex bytes (16 per row), and an ASCII sidebar. This is the foundational view that all other hex features build on.

## Acceptance Criteria
- [ ] New `HexView` SwiftUI view renders Data in three columns: offset (hex address), hex bytes, ASCII
- [ ] 16 bytes per row, space-separated, with a wider gap between byte 8 and 9
- [ ] Non-printable characters shown as `.` in ASCII column
- [ ] Alternating row backgrounds for readability
- [ ] Byte values color-coded: null bytes (dim), printable ASCII (default), high bytes (accent color)
- [ ] Offset gutter shows hex addresses (e.g. `00000000`, `00000010`, ...)
- [ ] Status bar shows file size and current offset
- [ ] Renders correctly for empty files (0 bytes)

## Notes
Use Canvas or a custom NSView for performance — standard SwiftUI Text views will be too slow for large files. Consider a virtual scrolling approach from the start (T-000023).
