## Goal
Detect binary files on open and offer to switch to hex mode. Allow manual toggling between text and hex mode for any file.

## Acceptance Criteria
- [ ] On file open, scan first 8KB for null bytes or invalid UTF-8 sequences to detect binary content
- [ ] When binary content detected, show alert: "This file appears to be binary. Open in hex mode?" with "Hex Mode" / "Text Mode" buttons
- [ ] Menu item "Editor > Hex Mode" toggles between text and hex view (Cmd+Shift+H)
- [ ] Hex mode toggle available for any file, not just detected binary files
- [ ] Current mode (Text / Hex) shown in status bar
- [ ] Switching from hex mode to text mode for a binary file shows a warning
- [ ] State persists per-document (switching tabs remembers each tab's mode)

## Notes
The binary detection heuristic should be fast (check first 8KB only). Files that fail UTF-8 decoding in `TextDocument(configuration:)` currently throw — this ticket provides the alternative path for those files.
