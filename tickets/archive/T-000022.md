## Goal
Add search capabilities to hex mode: find/replace by hex pattern or ASCII string, and go-to-offset navigation.

## Acceptance Criteria
- [ ] Find bar in hex mode supports searching by hex bytes (e.g. `FF D8 FF E0`) and ASCII string
- [ ] Toggle between hex pattern and ASCII string search modes
- [ ] All matches highlighted in hex view; current match distinctly highlighted
- [ ] Replace works in hex mode (replace hex bytes or ASCII)
- [ ] Go-to-offset dialog (Cmd+G in hex mode) accepts decimal or hex (`0x`) offset
- [ ] Navigating to an offset scrolls and selects the byte at that position
- [ ] Out-of-range offset shows inline error

## Notes
Reuse the existing `SearchReplaceView` UI where possible, extending it with a hex/ASCII mode toggle when in hex mode.
