## Goal
Allow copying and exporting hex selections in multiple developer-friendly formats.

## Acceptance Criteria
- [ ] Select a range of bytes in hex view (click + shift-click or click-drag)
- [ ] Right-click context menu offers "Copy As" submenu with formats:
  - Hex string (e.g. `FF D8 FF E0 00 10`)
  - C array (e.g. `{ 0xFF, 0xD8, 0xFF, 0xE0, 0x00, 0x10 }`)
  - Swift array (e.g. `[0xFF, 0xD8, 0xFF, 0xE0, 0x00, 0x10]`)
  - Raw bytes (binary data on pasteboard)
  - Hex dump text (full offset | hex | ASCII format)
- [ ] Cmd+C copies as hex string by default
- [ ] "Export Hex Dump" menu item exports full file or visible range as a `.txt` hex dump

## Notes
Standard `NSPasteboard` usage. For raw bytes, use a custom pasteboard type so other hex editors can paste them.
