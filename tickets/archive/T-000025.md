## Goal
Detect file type (ELF, PNG, MP4, JPEG, PDF, ZIP, etc.) from magic byte signatures and display the detected type in the hex view status bar

## Acceptance Criteria
- [ ] New `MagicBytes` module with a registry of file signatures (PNG, JPEG, GIF, PDF, ZIP, ELF, Mach-O, MP4, WAV, etc.)
- [ ] `static func detect(from data: Data) -> FileSignature?` returns detected type with name, description, and matched byte range
- [ ] Hex view status bar shows detected file type (e.g. "PNG Image" or "ELF Executable") when available
- [ ] Correctly handles files with no recognized signature (shows nothing extra)
- [ ] Unit tests for at least 5 common file signatures

## Notes
File: Create `qw/Hex/MagicBytes.swift`. Match against the first 16-32 bytes of the file. Common signatures: `89 50 4E 47` (PNG), `FF D8 FF` (JPEG), `25 50 44 46` (PDF), `50 4B 03 04` (ZIP), `7F 45 4C 46` (ELF), `CA FE BA BE` (Mach-O), `47 49 46 38` (GIF).
