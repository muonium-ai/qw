## Goal
Show a Data Inspector side panel in hex view that decodes bytes at the cursor position as int8/16/32/64, float/double, ASCII, hex, with an endianness toggle

## Acceptance Criteria
- [ ] Side panel appears in hex view showing decoded values at current cursor offset
- [ ] Displays offset (hex), raw hex bytes, and all interpretations simultaneously:
  - Int8 (signed/unsigned)
  - Int16 (signed/unsigned)
  - Int32 (signed/unsigned)
  - Int64 (signed/unsigned)
  - Float32 (IEEE 754)
  - Float64 / Double (IEEE 754)
  - ASCII / UTF-8 character(s)
- [ ] Endianness toggle (Little Endian / Big Endian) updates all multi-byte interpretations live
- [ ] Panel updates in real-time as cursor moves through hex view
- [ ] Gracefully handles edge cases: cursor near end of file (not enough bytes for Int64/Double shows "—")
- [ ] Panel can be shown/hidden via menu item or keyboard shortcut

## Notes
Create `qw/Hex/DataInspectorView.swift`. Read bytes from cursor position forward (up to 8 bytes for Int64/Double). Use Swift's `withUnsafeBytes` or manual byte assembly respecting the selected endianness. Display in a compact vertical list with labels on the left and values on the right. Show NaN/Inf explicitly for float values. Consider also showing binary representation for Int8.
