## Goal
Compare two binary files side-by-side in hex view, highlighting byte differences with offset-aligned rows, diff summary, and navigation between changed regions

## Acceptance Criteria
- [ ] "Compare With..." menu item (Cmd+Shift+D) opens a file picker to select the second file
- [ ] Side-by-side hex view: file A on left, file B on right, offset-aligned rows
- [ ] Differing bytes highlighted in red/orange; identical bytes in default color
- [ ] Offset gutter shared between both panes for alignment
- [ ] Diff summary bar showing: total bytes, changed bytes, added/removed bytes (if files differ in size)
- [ ] Navigate between diff regions with "Next Difference" / "Previous Difference" (Cmd+G / Cmd+Shift+G in diff mode)
- [ ] Handles files of different sizes — shorter file shows empty/padding rows beyond its length
- [ ] Uses mmap for both files to support large file comparison
- [ ] Synchronized scrolling between left and right panes

## Notes
Create `qw/Hex/HexDiffView.swift` for the side-by-side layout and `qw/Hex/BinaryDiff.swift` for the diff engine. The diff engine should produce a list of `DiffRegion(offset:, lengthA:, lengthB:, type: .changed|.added|.removed|.equal)`. For performance, compute diffs lazily per visible page rather than scanning the entire file upfront. Format for changed rows:
```
00001230:  A: FF 00 12    B: FF 01 12
                 ^^              ^^
```
