## Goal
Build a browser-based hex viewer demo using Rust compiled to WASM with Canvas/WebGL rendering, drag-and-drop file loading, and AI-powered binary structure explanation

## Acceptance Criteria

### Rust / WASM Core
- [ ] Rust crate (`qw-wasm/`) with hex formatting, magic byte detection, and byte decoding logic
- [ ] Compiles to WASM via `wasm-pack` with JS bindings
- [ ] Exports: `parse_file(bytes) -> FileInfo`, `format_hex_row(offset, bytes) -> HexRow`, `detect_file_type(bytes) -> String`, `decode_bytes(offset, bytes, endian) -> DecodedValues`
- [ ] Handles files up to 100 MB via streaming / chunked access (no full copy into WASM linear memory)

### Browser UI
- [ ] Single-page HTML/JS app with Canvas or WebGL rendering for hex grid
- [ ] Drag-and-drop file loading (File API / FileReader)
- [ ] Virtual scrolling — only renders visible rows from the WASM backend
- [ ] Three-column hex layout matching native app: offset | hex bytes | ASCII
- [ ] Byte color coding: null (dim), printable ASCII (default), high bytes (accent)
- [ ] Click-to-select byte with Data Inspector panel showing int8/16/32/64, float/double
- [ ] Endianness toggle (LE/BE)

### AI Structure Explanation
- [ ] "Explain" button sends first 256 bytes + detected file type to Claude API
- [ ] AI response rendered in a side panel explaining file structure, headers, and notable fields
- [ ] Streaming response display
- [ ] Works with API key entered by user (stored in localStorage, never sent to any server except Anthropic)

### Demo / Deployment
- [ ] Deployable as static site (GitHub Pages / Netlify)
- [ ] Landing page with brief description and "Drop a file to inspect" prompt
- [ ] Works in Chrome, Firefox, Safari
- [ ] Total WASM bundle < 500 KB gzipped

## Notes
Directory: `qw-wasm/` at repo root. Use `wasm-bindgen` for JS interop. For the AI explain feature, call the Claude API directly from the browser (client-side only, no backend). Canvas rendering preferred over DOM for performance with large files. Consider using `web-sys` for Canvas API access from Rust, or a thin JS Canvas layer that reads formatted rows from WASM.
