## Goal
Design and implement a reusable sandbox framework that all executable runners (native, WASM, Wine, JVM) use. Must enforce: no network access by default, restricted filesystem (read-only tmpdir only), no process spawning, memory limits, CPU time limits, stdout/stderr capture with size caps, kill switch with timeout. Use macOS sandbox-exec (seatbelt) profiles or App Sandbox entitlements. This is the foundation — no execution tickets should ship without this.
