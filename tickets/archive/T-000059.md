## Goal
Run JAR files via java -jar with strict security constraints. Use Java SecurityManager (or the newer Agents/module system for Java 17+) with a policy that denies: all network (SocketPermission), all file write except tmpdir (FilePermission), process exec (RuntimePermission), system property writes, class loader creation, native library loading. Additionally wrap in sandbox-exec seatbelt profile as defense-in-depth. Detect java on PATH, verify version, prompt if missing. Enforce -Xmx256m heap limit, CPU timeout (30s). Capture stdout/stderr, display in terminal panel.
