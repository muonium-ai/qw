## Goal
Create two UI components: (1) Pre-execution confirmation dialog showing file name, detected format, sandbox restrictions summary (no network, filesystem limits, memory/CPU limits), and Run/Cancel buttons with a warning that execution carries risk. (2) Terminal output panel (TerminalOutputView) that displays captured stdout/stderr in a monospace scrollable view with ANSI color support, execution status (running/completed/killed/error), elapsed time, exit code, and a Kill button for running processes.
