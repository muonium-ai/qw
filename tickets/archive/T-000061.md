## Goal
HexView crashes on large files due to AttributeGraph exhaustion. Each row creates 32 subviews with 64 gesture modifiers. For a 1MB file (65K rows) that overwhelms SwiftUI. Fix by reducing per-byte views: use a single Text per row section with one gesture handler that calculates the byte index from click position, instead of individual per-byte Text views with separate gestures.
