## Goal
The film/media toolbar button in HexView shows for all file types. Clicking it on a non-media file (e.g. SQLite) shows MediaMetadataPanel stuck on 'Probing media...' forever because triggerFFprobeIfNeeded returns early but showMediaMetadata was already set to true. Fix: only show the button for audio/video files, and handle the case where ffprobe is not triggered.
