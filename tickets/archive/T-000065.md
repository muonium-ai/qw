## Goal
The info button in hex view only shows the Data Inspector when a byte is selected — otherwise it appears to do nothing. Add a File Info section at the top of the Data Inspector panel (or as a separate always-visible panel) showing: filename, file path, file size (bytes + human-readable), detected format (magic bytes name), format category, file extension, creation/modification dates, and permissions.
