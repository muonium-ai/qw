## Root Cause
The crash was earlier than AppKit rasterization: instantiating the reference-type `DocumentExporter` itself was enough to crash the app-hosted macOS 26 test runner. Extracting a value-type `DocumentExportSession` let the test exercise the shared PNG export pipeline, including file output, without touching the crashing class lifecycle.

## Possible Approaches

- Use XCUITest to drive the export through the app UI instead
- Test the AttributedString creation separately from the PNG rendering
- Wait for Apple fix
